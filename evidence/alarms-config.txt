# What each alarm means
# crowdmap-*-errors          >= 1 unhandled Lambda error in 5 min (code fault, bad deploy, S3 access)
# crowdmap-bookings-throttled >= 1 throttle on the single-writer Lambda (booking burst exceeds 1 instance)
# crowdmap-http-5xx          >= 5 server errors in 5 min (users seeing failures)
# crowdmap-http-4xx          >= 50 client errors in 5 min, mostly 429 from API Gateway throttling
#                            (load spike or abuse; the throttle is protecting the backend)
# crowdmap-http-latency      p95 latency >= 3000 ms (slow cold starts or overloaded backend)
# INSUFFICIENT_DATA is the normal state right after creation; alarms move to OK once metrics arrive.
